tipoEvento : String

(Usuario que realizó la acción)

9. CONFIGURACION_HISTORIAL

Para cumplir RN16 e I3.

Registra todos los cambios de parámetros globales.

Atributos
idHistorialConfiguracion : Integer

fechaEvento : DateTime

nombreParametro : String

valorAnterior : String

valorNuevo : String

motivoCambio : String
Relaciones
CONFIGURACION_HISTORIAL -> CONFIGURACION

CONFIGURACION_HISTORIAL -> USUARIO
(Actor)

1. CONFIGURACION

Representa el valor actual de cada parámetro configurable del sistema.

Atributos
idConfiguracion : Integer

nombreParametro : String

valorParametro : String

descripcionParametro : String

fechaModificacion : DateTime
Ejemplos de registros
jwt_web_expiration

jwt_vr_expiration

duracion_maxima_sesion

plantilla_certificado

correo_notificacion_asignacion

correo_notificacion_aprobacion
Relaciones
CONFIGURACION_HISTORIAL -> CONFIGURACION
[0..* → 1]

No necesita más relaciones.

2. EMPRESA_ADMINISTRADOR

Permite registrar qué administrador administra qué empresa y mantener historial completo de asignaciones.

Atributos
fechaAsignacion : Date

fechaRevocacion : Date

asignadoPor : Usuario

revocadoPor : Usuario
Relaciones
EMPRESA_ADMINISTRADOR -> Empresa
[0..* → 1]

EMPRESA_ADMINISTRADOR -> USUARIO
[0..* → 1]

Donde el USUARIO asociado debe ser un administrador de empresa.


3. PERMISO_ENDPOINT

Actualmente tienen:

Permiso → Endpoint

pero sin entidad asociativa.

Esta clase permite auditar altas y bajas de permisos sobre endpoints.

Atributos
fechaAsignacion : DateTime

fechaBaja : DateTime

asignadoPor : Usuario

revocadoPor : Usuario
Relaciones
PERMISO_ENDPOINT -> Permiso
[0..* → 1]

PERMISO_ENDPOINT -> ENDPOINT
[0..* → 1]
